## 🗄️ 数据库表结构

### goods 表（商品表）
```sql
CREATE TABLE goods (
    itemID INT AUTO_INCREMENT PRIMARY KEY,     -- 商品ID
    itemName VARCHAR(50) NOT NULL,             -- 商品名称
    needPoint INT NOT NULL,                    -- 所需积分
    `desc` VARCHAR(255)                        -- 商品描述
);
```

### pointop 表（交易记录表）
```sql
CREATE TABLE pointop (
    opID INT AUTO_INCREMENT PRIMARY KEY,       -- 交易ID
    userID VARCHAR(20) NOT NULL,               -- 用户ID
    pointOP VARCHAR(50) NOT NULL,              -- 积分变化（如"-1"）
    detail VARCHAR(255),                       -- 交易详情（如"兑换1"）
    `time` DATETIME DEFAULT CURRENT_TIMESTAMP, -- 操作时间
    FOREIGN KEY (userID) REFERENCES user(userphone)
);
```

## 🔄 业务流程

### 用户兑换商品
```
1. 用户登录系统
2. 进入积分商城（导航栏或首页菜单）
3. 查看商品列表和当前积分
4. 点击某商品的"兑换"按钮
5. 确认兑换对话框
6. 发送 POST 请求到 /exchangeGoods
   - 参数：itemID, needPoints
7. ExchangeGoodsServlet 处理：
   - 验证用户登录状态
   - 检查积分是否足够
   - 扣除积分（UPDATE points）
   - 记录交易（INSERT pointop）
   - 返回成功/失败信息
8. 页面刷新，显示新积分
```

### 管理员添加商品
```
1. 管理员访问 /Administrator/AddGoods.html
2. 输入商品名称、所需积分、描述
3. 点击"添加商品"
4. 发送 POST 请求到 /addGoods
   - 参数：itemName, needPoint, desc
5. AddGoodsServlet 处理：
   - 验证参数
   - 插入数据库（INSERT goods）
   - itemID 自动自增
   - 返回成功/失败信息
6. 商品立即出现在商城中
```

## 📞 常见问题

### 兑换后积分没变？
- 检查 pointop 表是否创建
- 查看 Tomcat 日志
- 确保数据库连接正常

### 兑换按钮一直禁用？
- 检查用户积分值
- 检查商品的 needPoint
- 刷新页面重新加载

### 添加商品不成功？
- 检查参数是否为空
- 查看 Tomcat 日志
- 确保 goods 表存在

### 分页不工作？
- 检查商品数是否超过9个
- 查看分页参数传递
- 检查 SQL LIMIT OFFSET
