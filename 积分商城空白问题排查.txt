积分商城显示空白 - 问题排查和解决
==================================

## 问题现象
点击积分商城后页面显示空白

## 可能原因和解决方案

### 原因1：数据库表未创建 ⚠️

**检查方法**：
```bash
mysql -u root -p
USE web_demo;
SHOW TABLES;
```

**查看是否有这两个表**：
- `goods` - 商品表
- `pointop` - 交易记录表

**解决方案**：
如果没有这两个表，执行以下SQL：

```sql
USE web_demo;

-- 创建goods表
CREATE TABLE IF NOT EXISTS goods (
    itemID INT AUTO_INCREMENT PRIMARY KEY,
    itemName VARCHAR(50) NOT NULL,
    needPoint INT NOT NULL,
    `desc` VARCHAR(255)
);

-- 创建pointop表
CREATE TABLE IF NOT EXISTS pointop (
    opID INT AUTO_INCREMENT PRIMARY KEY,
    userID VARCHAR(20) NOT NULL,
    pointOP VARCHAR(50) NOT NULL,
    detail VARCHAR(255),
    `time` DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (userID) REFERENCES user(userphone)
);

-- 添加测试商品
INSERT INTO goods (itemID, itemName, needPoint, `desc`)
VALUES (1, '666', 1, 'good');

-- 验证
SELECT * FROM goods;
```

## 常见错误和解决

### 错误1：HTTP Status 404
**原因**：文件不存在或路径错误
**解决**：
- 检查文件是否在 `src/main/webapp/Prize/DisplayPrize.jsp`
- 重新编译部署
- 确认 WAR 包中包含该文件

### 错误2：HTTP Status 500
**原因**：JSP 编译错误或 Java 异常
**解决**：
- 查看 Tomcat 日志
- 检查数据库连接
- 检查 goods 表是否存在

### 错误3：页面空白，无错误
**原因**：JSP 中的 Java 代码有异常但被吞掉
**解决**：
- 查看 Tomcat logs/catalina.out
- 在 JSP 开头添加：`<%@ page errorPage="error.jsp" %>`
- 检查数据库表是否存在

### 错误4：ClassNotFoundException: com.mysql.cj.jdbc.Driver
**原因**：MySQL 驱动未包含
**解决**：
- 检查 pom.xml 是否有 MySQL 依赖
- 执行 `mvn clean install`
- 确认 WEB-INF/lib 中有 mysql-connector-java.jar
