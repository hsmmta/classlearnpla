## 问题概述

用户报告无法进入资料区和讨论区，经过诊断发现存在多个问题：

1. **Session属性名不一致** - 多个Servlet使用错误的session属性名
2. **SQL语法错误** - 使用了数据库中不存在的列名
3. **路径配置问题** - JSP中使用了硬编码的绝对路径
4. **缺少会话检查** - 某些Servlet没有验证用户登录状态

## 修复详情

### Phase 1：Session属性名修正

**背景**：LoginServlet中设置的是 `session.setAttribute("userID", userID)`（此处userID实际为用户手机号），但多个Servlet错误地尝试获取 `getAttribute("phone")`。

**修复的19个Servlet**：

3. EditMaterialServlet.java (doGet和doPost)

   - `getAttribute("phone")` → `getAttribute("userID")`

#### 讨论相关（5个）

### Phase 2：数据库列名修正

**背景**：SQL错误 `Unknown column 'userID' in 'where clause'`

原因：数据库user表的主键列名是 `userphone`，但代码中多个地方使用了 `WHERE userID = ?`

**修复的4个Servlet**：

11. ChangeUserInfoServlet.java
    ```
    原：WHERE userID = ?
    新：WHERE userphone = ?
    ```

12. DeleteAccountServlet.java (两处)
    ```
    verifyPassword方法：WHERE userID = ? → WHERE userphone = ?
    updateUserStatus方法：WHERE userID = ? → WHERE userphone = ?
    ```

13. ChangePasswordServlet.java (两处)
    ```
    verifyOldPassword方法：WHERE userID = ? → WHERE userphone = ?
    updateNewPassword方法：WHERE userID = ? → WHERE userphone = ?
    ```

### Phase 3：JSP路径修正

**背景**：某些JSP文件使用了硬编码的绝对路径，在不同部署环境下可能导致404错误。

**修复的3个JSP文件**：

1. SearchMaterial.jsp
   ```
   form action: /material/search → ${pageContext.request.contextPath}/material/search
   查看链接: /material/view → ${pageContext.request.contextPath}/material/view
   ```

2. AddMaterial.jsp
   ```
   form action: /material/upload → ${pageContext.request.contextPath}/material/upload
   ```

3. EditMaterial.jsp
   ```
   form action: /material/edit → ${pageContext.request.contextPath}/material/edit
   ```

## 数据库设计说明

### user表结构
```
CREATE TABLE user (
  userphone VARCHAR(20) PRIMARY KEY,    -- 用户手机号
  userPassword VARCHAR(50),              -- 密码
  userName VARCHAR(20),                  -- 用户昵称
  classID VARCHAR(15),                   -- 班级编号
  studentID VARCHAR(15),                 -- 学号
  gender VARCHAR(10),                    -- 性别 (male/female)
  userEmail VARCHAR(50),                 -- 邮箱
  userStatus INT DEFAULT 1               -- 状态 (1=激活, 0=未激活, -1=已注销)
);
```

### 重要概念
- **userphone** 是user表的主键
- **Session中的userID** 存储的实际是用户的手机号（userphone）
- **Material、Question等表中的userID** 是外键，存储用户手机号

### 列名对应关系
| 表名 | 列名 | 类型 | 说明 |
|------|------|------|------|
| user | userphone | PRIMARY KEY | 用户手机号 |
| material | userID | 普通列 | 上传者手机号 |
| question | userID | 普通列 | 提问者手机号 |
| question_comment | userID | 普通列 | 评论者手机号 |

## 常见问题及解决

### 问题1：仍然无法进入资料区/讨论区
**原因**：可能是用户未登录或Session已过期
**解决**：确保用户已成功登录，检查Session设置

### 问题2：显示"数据库连接失败"
**原因**：DBUtil中的数据库连接信息不正确
**解决**：检查URL、用户名、密码，确保MySQL正在运行

### 问题3：操作报错"Unknown column"
**原因**：数据库表结构与代码不匹配
**解决**：检查数据库表是否存在，列名是否正确

### 问题4：路径404错误
**原因**：应用部署路径与代码路径不匹配
**解决**：使用contextPath而不是硬编码路径
