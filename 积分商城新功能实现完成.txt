## 功能说明

### 功能1：兑换历史

**访问路径**：
- 从积分商城点击"兑换历史"链接
- 直接访问：`/Prize/ExchangeHistory.jsp`

**显示内容**：
- 编号（opID）
- 积分变化（pointOP）- 绿色表示增加，红色表示减少
- 详情（detail）- 如"兑换1"、"管理员增加积分"
- 时间（time）- 格式：yyyy-MM-dd HH:mm:ss

**数据来源**：
- 从 `pointop` 表查询该用户的所有记录
- 按时间倒序排列（最新的在前）

---

### 功能2：管理员修改用户积分

**访问路径**：
- `/Administrator/ModifyUserPoints.html`

**使用流程**：
1. 输入用户ID（手机号）
2. 点击"查询当前积分"
3. 显示用户当前积分
4. 选择操作类型：
   - **增加积分**：在当前积分基础上增加
   - **减少积分**：在当前积分基础上减少（最低为0）
   - **设置积分**：直接设置为指定积分
5. 输入积分数量
6. 输入操作说明（可选）
7. 点击"确认修改"

**操作示例**：

**示例1：增加积分**
```
用户ID: 13800000001
当前积分: 10
操作: 增加积分
数量: 5
说明: 活动奖励
结果: 积分变为 15
记录: +5, "管理员增加积分：活动奖励"
```

**示例2：减少积分**
```
用户ID: 13800000001
当前积分: 10
操作: 减少积分
数量: 3
说明: 违规扣除
结果: 积分变为 7
记录: -3, "管理员减少积分：违规扣除"
```

**示例3：设置积分**
```
用户ID: 13800000001
当前���分: 10
操作: 设置积分
数量: 100
说明: 系统补偿
结果: 积分变为 100
记录: +90, "管理员设置积分为100：系统补偿"
```

## API 接口说明

### 1. 查询用户积分

**URL**：`/queryUserPoints`
**方法**：POST
**参数**：
- `userID` (String) - 用户ID（手机号）

**返回**：
```json
{
  "success": true,
  "points": 10,
  "msg": "查询成功"
}
```

---

### 2. 修改用户积分

**URL**：`/modifyUserPoints`
**方法**：POST
**参数**：
- `userID` (String) - 用户ID（手机号）
- `operation` (String) - 操作类型（add/subtract/set）
- `pointAmount` (int) - 积分数量
- `reason` (String) - 操作说明（可选）

**返回**：
```json
{
  "success": true,
  "msg": "积分修改成功"
}
```

## 常见问题

### Q：兑换历史页面显示空白？
A：
1. 检查 pointop 表是否存在
2. 确认用户是否有兑换记录
3. 查看 Tomcat 日志是否有错误

### Q：修改积分不成功？
A：
1. 检查用户ID是否正确
2. 确认 points 表中有该用户记录
3. 查看 Tomcat 日志

### Q：兑换历史中文乱码？
A：
1. 确保数据库字符集为 UTF-8
2. 检查 JSP 页面编码设置
3. 检查 Tomcat 配置

## 技术细节

### 积分变化显示样式
```css
.point-change.positive {
    color: #28a745;  /* 绿色：增加 */
}

.point-change.negative {
    color: #dc3545;  /* 红色：减少 */
}
```

### 事务处理
修改积分时使用事务，确保：
1. 更新 points 表
2. 插入 pointop 记录

两个操作要么都成功，要么都失败，保证数据一致性。
