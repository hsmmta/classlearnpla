积分表创建 - 外键约束错误解决方案
====================================

## 错误原因

```
ERROR 1822 (HY000): Failed to add the foreign key constraint.
Missing index for constraint 'points_ibfk_2' in the referenced table 'user'
```

**原因**：MySQL 要求外键引用的列必须有索引。你的 SQL 中：
- `FOREIGN KEY (userID) REFERENCES user(userphone)` ✅ 可以（userphone是主键，已有索引）
- `FOREIGN KEY (userName) REFERENCES user(userName)` ❌ 不行（userName没有索引）

---

## 解决方案（3选1）

### 方案1：简化版（推荐 ⭐）

**优点**：最简单，无需修改user表**

只用 `userID` 作为外键，删除 `userName` 的外键约束：

```sql
DROP TABLE IF EXISTS points;

CREATE TABLE points (
    userID VARCHAR(20) PRIMARY KEY,
    userName VARCHAR(20),
    points INT DEFAULT 0,
    FOREIGN KEY (userID) REFERENCES user(userphone)
);

-- 初始化数据
INSERT IGNORE INTO points (userID, userName, points)
SELECT userphone, userName, 0 FROM user;
```

**执行步骤**：
1. 如果points表已存在，先删除：`DROP TABLE IF EXISTS points;`
2. 执行上面的 SQL 语句
3. 验证：`DESC points;`

---

### 方案2：为userName添加索引（完整版）

**优点**：保留原来的两个外键约束

为 `user` 表的 `userName` 列添加唯一索引：

```sql
-- 第一步：为user表添加唯一索引
ALTER TABLE user ADD UNIQUE INDEX idx_userName (userName);

-- 第二步：删除旧的points表（如果存在）
DROP TABLE IF EXISTS points;

-- 第三步：创建带两个外键的points表
CREATE TABLE points (
    userID VARCHAR(20) PRIMARY KEY,
    userName VARCHAR(20),
    points INT DEFAULT 0,
    FOREIGN KEY (userID) REFERENCES user(userphone),
    FOREIGN KEY (userName) REFERENCES user(userName)
);

-- 第四步：初始化数据
INSERT IGNORE INTO points (userID, userName, points)
SELECT userphone, userName, 0 FROM user;
```

**执行步骤**：
1. 执行第一步添加索引
2. 执行第二、三、四步创建表和初始化数据
3. 验证：`DESC points;`

---

### 方案3：删除userName外键（折中方案）

```sql
DROP TABLE IF EXISTS points;

CREATE TABLE points (
    userID VARCHAR(20) PRIMARY KEY,
    userName VARCHAR(20),
    points INT DEFAULT 0,
    FOREIGN KEY (userID) REFERENCES user(userphone)
    -- 注意：userName不设为外键，只作为普通列存储用户名
);

INSERT IGNORE INTO points (userID, userName, points)
SELECT userphone, userName, 0 FROM user;
```

## 常见问题

### Q：执行 SQL 时还是报错怎么办？
A：
1. 检查是否先删除了旧的 points 表：`DROP TABLE IF EXISTS points;`
2. 检查 user 表是否存在：`SHOW TABLES LIKE 'user';`
3. 检查 user 表的结构：`DESC user;`

### Q：我想保留两个外键约束怎么办？
A：执行方案2，它会为 userName 列添加索引。

### Q：数据没有初始化怎么办？
A：手动执行初始化 SQL：
```sql
INSERT IGNORE INTO points (userID, userName, points)
SELECT userphone, userName, 0 FROM user;
```

### Q：如何删除已创建的 points 表？
A：
```sql
DROP TABLE points;
```
