发布问题和上传资料外键错误 - 修复完成
==============================

## 🔴 问题描述

### 错误信息
```
java.sql.SQLIntegrityConstraintViolationException:
Cannot add or update a child row: a foreign key constraint fails
(`web_demo`.`question`, CONSTRAINT `question_ibfk_1`
FOREIGN KEY (`userID`) REFERENCES `user` (`userphone`))
```

### 问题原因
1. **Session 中的 userID 不一致**：
   - 某些登录流程设置的 `userID` 可能不是用户的手机号
   - 数据库中 `question.userID` 外键关联到 `user.userphone`
   - 导致外键约束失败

2. **缺少用户验证**：
   - 发布问题和上传资料时没有验证 userID 是否真实存在
   - 直接插入可能不存在的 userID

## 📝 总结

### 问题根源
Session 中的 userID 与 user 表中的 userphone 不一致，导致外键约束失败。

### 解决方案
1. 在发布问题和上传资料时，先验证 userID 是否存在于 user 表
2. 如果不存在，提示用户重新登录
3. 确保只有有效的 userID 才会被插入 question 和 material 表
