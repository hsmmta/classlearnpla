## 问题1：管理员看不到待审核的问题

### 诊断步骤

#### 1. 检查是否有待审核的问题
```sql
USE web_demo;
SELECT * FROM question WHERE questionState = '待审核';
```

如果查询结果为空，说明用户提交的问题没有被保存为"待审核"状态。

#### 2. 检查问题提交是否成功
用户提交问题后应该看到提示信息。如果没有看到，可能问题没有成功保存。

#### 3. 检查 AuditQuestion.jsp 是否能访问
访问：`/discussion/audit`

如果显示"无权限"，说明：
- 用户没有以管理员身份登录
- Session 中的 `userType` 不是 "admin"

#### 4. 检查 AuditQuestionServlet 是否工作
```
访问 /discussion/audit 后，应该看到：
- 如果有待审核问题：显示问题表格
- 如果没有待审核问题：显示"没有待审核的问题。"
```

### 修复方案

#### 修复1：确保问题被正确保存为"待审核"
检查 AskQuestionServlet 第44行是否设置了状态：
```java
pstmt.setString(4, userID);  // 验证userID
pstmt.setString(7, "待审核");  // 确保这行存在
```

#### 修复2：修改 AuditQuestion.jsp 中的链接
原来的链接：`/discussion/view_content?id=...`（错误，不存在的路由）
修改后的链接：`/discussion/view?id=...`（正确，对应 ViewQuestionServlet）

**已修复：✅**

## SQL 查询辅助

### 查看所有未审核的问题
```sql
SELECT
    q.questionID,
    q.questionTitle,
    q.questionState,
    q.creationTime,
    u.userName
FROM question q
LEFT JOIN user u ON q.userID = u.userphone
WHERE q.questionState = '待审核'
ORDER BY q.creationTime DESC;
```

### 查看所有已设置最满意答案的问题
```sql
SELECT
    q.questionID,
    q.questionTitle,
    q.bestAnswerID,
    qc.userID as answerOwner,
    u.userName
FROM question q
LEFT JOIN question_comment qc ON q.bestAnswerID = qc.commentID
LEFT JOIN user u ON qc.userID = u.userphone
WHERE q.bestAnswerID IS NOT NULL;
```
