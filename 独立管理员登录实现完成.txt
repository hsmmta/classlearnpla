独立管理员登录页面 - 实现完成
===========================

## 实现内容 ✅

### 1. 创建独立的管理员登录页面 ✅
**文件**：`src/main/webapp/auth/adminSignin.html`

**特点**：
- 红色主题，区别于用户登录
- 只需要输入管理员账号和密码
- 没有验证码登录选项
- 有"管理员专用"标识
- 提示普通用户返回用户登录

### 2. 创建管理员登录Servlet ✅
**文件**：`src/main/java/org/example/servlet/AdminLoginServlet.java`

**功能**：
- 接收管理员账号和密码
- 验证 admin 表
- 设置管理员 session
- 返回 JSON 响应
- 登录成功跳转到 `/Administrator/index.jsp`

### 3. 在用户登录页添加入口 ✅
**修改文件**：`src/main/webapp/auth/signin.html`

**添加内容**：
- 在"没有账号？点击注册"下方
- 添加红色加粗的"管理员登录入口 →"链接
- 点击跳转到管理员登录页面

## 使用流程

### 普通用户登录
```
访问：/auth/signin.html
↓
输入手机号 + 密码（或验证码）
↓
点击"登录"
↓
跳转到用户首页 /home/index.jsp
```

### 管理员登录
```
访问：/auth/signin.html
↓
点击"管理员登录入口 →"
↓
跳转到：/auth/adminSignin.html
↓
输入管理员账号 + 密码
↓
点击"登录"
↓
跳转到管理员页面 /Administrator/index.jsp
```

## API 接口

### 管理员登录接口

**URL**：`/adminLogin`
**方法**：POST
**参数**：
- `adminID` (String) - 管理员账号
- `adminPassword` (String) - 管理员密码

**返回**：
```json
// 成功
{
  "success": true,
  "msg": "登录成功",
  "redirectUrl": "/焚决/Administrator/index.jsp"
}

// 失败
{
  "success": false,
  "msg": "管理员账号或密码错误"
}
```

## 常见问题

### Q：管理员登录失败？
A：
1. 检查 admin 表是否存在
2. 检查管理员账号和密码是否正确
3. 查看 Tomcat 日志

### Q：点击"管理员登录入口"没反应？
A：
1. 清除浏览器缓存
2. 检查文件是否存在：`/auth/adminSignin.html`
3. 重启 Tomcat

### Q：管理员登录后跳转失败？
A：
1. 检查 `/Administrator/index.jsp` 是否存在
2. 查看浏览器控制台是否有错误
3. 检查 Tomcat 日志
