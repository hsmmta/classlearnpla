## 数据库要求

### material 表需要 materialState 列

```sql
-- 检查列是否存在
SHOW COLUMNS FROM material LIKE 'materialState';

-- 如果不存在，添加列
ALTER TABLE material
ADD COLUMN materialState VARCHAR(20) DEFAULT '待审核'
COMMENT '资料状态：待审核、审核通过、审核不通过';

-- 更新现有资料为已通过（可选）
UPDATE material SET materialState = '审核通过'
WHERE materialState IS NULL OR materialState = '';
```

### question 表需要 questionState 列

```sql
-- 检查列是否存在
SHOW COLUMNS FROM question LIKE 'questionState';

-- 如果不存在，添加列
ALTER TABLE question
ADD COLUMN questionState VARCHAR(20) DEFAULT '待审核'
COMMENT '问题状态：待审核、审核通过、审核不通过';

-- 更新现有问题为已通过（可选）
UPDATE question SET questionState = '审核通过'
WHERE questionState IS NULL OR questionState = '';
```

## 审核工作流

### 资料审核流程

```
用户端：
1. 用户上传资料 → materialState = '待审核'
2. 资料不在资料区显示（因为状态不是'审核通过'）

管理员端：
3. 管理员登录 → 进入"资料审核"
4. 查看所有 materialState = '待审核' 的资料
5. 点击"通过" → materialState = '审核通过'
   或点击"拒绝" → materialState = '审核不通过'

用户端：
6. 已通过的资料在资料区显示
7. 被拒绝的资料不显示
```

### 问题审核流程

```
用户端：
1. 用户发布问题 → questionState = '待审核'
2. 问题不在讨论区显示（因为状态不是'审核通过'）

管理员端：
3. 管理员登录 → 进入"问题审核"
4. 查看所有 questionState = '待审核' 的问题
5. 点击"通过" → questionState = '审核通过'
   或点击"拒绝" → questionState = '审核不通过'

用户端：
6. 已通过的问题在讨论区显示
7. 被拒绝的问题不显示
```

## API 接口

```
URL: /material/audit
方法: GET
权限: 管理员（userType = "admin"）
返回: 待审核资料列表页面

```

## 常见问题

### Q：点击审核链接显示"无权限"？
A：
1. 确认已使用管理员账号登录
2. 确认 session 中 userType = "admin"
3. 查看 Tomcat 日志

### Q：审核页面显示空白？
A：
1. 检查数据库表是否有 materialState / questionState 列
2. 查看 Tomcat 日志是否有SQL错误
3. 确认数据库连接正常

### Q：用户上传的内容没有设置为"待审核"？
A：
1. 检查上传Servlet是否设置了状态
2. 应该在插入时设置：`INSERT INTO material (..., materialState) VALUES (..., '待审核')`

### Q：审核后用户端还是看不到？
A：
1. 检查用户端查询SQL是否有状态过滤
2. 应该有：`WHERE materialState = '审核通过'`
