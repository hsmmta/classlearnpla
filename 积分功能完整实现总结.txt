**表结构**：
```sql
CREATE TABLE points (
    userID VARCHAR(20) PRIMARY KEY,      -- 用户ID（手机号），既是主键又是外键
    userName VARCHAR(20),                 -- 用户名，外键
    points INT DEFAULT 0,                 -- 积分，默认为0

    FOREIGN KEY (userName) REFERENCES user(userName)
```

## 技术细节

### 积分显示逻辑（getUserInfo.jsp）

```jsp
<%
    // 获取用户ID
    String userID = (String) session.getAttribute("userID");
    int userPoints = 0;

    if (userID != null && !userID.isEmpty()) {
        // 从points表查询积分
        try {
            Connection conn = DriverManager.getConnection(...);
            PreparedStatement pstmt = conn.prepareStatement(
                "SELECT points FROM points WHERE userID = ?"
            );
            pstmt.setString(1, userID);
            ResultSet rs = pstmt.executeQuery();

            if (rs.next()) {
                userPoints = rs.getInt("points");
            } else {
                // 如果无记录则创建一条
                // INSERT INTO points (userID, userName, points) VALUES (?, ?, 0)
                userPoints = 0;
            }
        } catch (Exception e) {
            userPoints = 0; // 异常时默认为0
        }
    }
%>
```

## 数据库查询示例

### 查询所有用户的积分
```sql
SELECT u.userphone, u.userName, p.points
FROM user u
LEFT JOIN points p ON u.userphone = p.userID
ORDER BY p.points DESC;
```

### 查询单个用户的积分
```sql
SELECT points FROM points WHERE userID = '13800000001';
```

## 常见问题

### Q：创建表时报错"Table 'points' already exists"？
A：说明 points 表已存在，可以直接使用。如果需要重建，先执行 `DROP TABLE points;`

### Q：个人中心显示积分时出错？
A：确保：
1. points 表已创建
2. Tomcat 已重启
3. 浏览器缓存已清除

### Q：新用户注册时积分没有自动创建？
A：确保：
1. RegisterServlet 已编译最新版本
2. 应用已重新部署

### Q：如何为已有用户批量添加积分？
A：使用 SQL：
```sql
INSERT IGNORE INTO points (userID, userName, points)
SELECT userphone, userName, 0 FROM user
WHERE userphone NOT IN (SELECT userID FROM points);
```
