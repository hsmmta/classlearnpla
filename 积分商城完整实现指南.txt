## 数据库表创建

### 1. 执行 SQL 创建表

在 MySQL 中执行以下SQL（已保存在 创建积分商城表.sql）：

```sql
USE web_demo;

-- 创建goods表（商品表）
CREATE TABLE IF NOT EXISTS goods (
    itemID INT AUTO_INCREMENT PRIMARY KEY COMMENT '商品ID',
    itemName VARCHAR(50) NOT NULL COMMENT '商品名称',
    needPoint INT NOT NULL COMMENT '所需积分',
    `desc` VARCHAR(255) COMMENT '商品描述'
);

-- 创建pointop表（交易记录表）
CREATE TABLE IF NOT EXISTS pointop (
    opID INT AUTO_INCREMENT PRIMARY KEY COMMENT '交易记录ID',
    userID VARCHAR(20) NOT NULL COMMENT '用户ID',
    pointOP VARCHAR(50) NOT NULL COMMENT '积分变化，如+10或-1',
    detail VARCHAR(255) COMMENT '交易详情，如兑换123或获得积分',
    `time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '操作时间',
    FOREIGN KEY (userID) REFERENCES user(userphone)
);

-- 添加初始商品
INSERT INTO goods (itemID, itemName, needPoint, `desc`)
VALUES (1, '666', 1, 'good');
```

### 2. 验证表创建

```sql
DESC goods;
DESC pointop;
SELECT * FROM goods;
```

## 功能说明

### 1. 积分商城页面 (DisplayPrize.jsp)

**特性**：
- 显示当前用户的积分
- 3x3 网格展示商品（每页9个）
- 自动翻页
- 商品不足时显示"暂无商品"
- 兑换按钮自动禁用（积分不足时）
- 商品图片来自 `/images/example.webp`

**显示内容**：
- 商品图片（200x200像素）
- 商品名称
- 所需积分（橙色加粗）
- 商品描述
- 兑换按钮

### 2. 兑换商品 (ExchangeGoodsServlet)

**流程**：
1. 用户点击"兑换"按钮
2. 确认对话框
3. 向 `/exchangeGoods` 发送 POST 请求
4. 验证用户积分是否足够
5. 扣除积分
6. 记录到 pointop 表
7. 刷新页面显示新积分

**参数**：
- `itemID` - 商品ID
- `needPoints` - 所需积分

**返回**：
```json
{
  "success": true/false,
  "msg": "兑换成功/失败原因"
}
```

### 3. 添加商品 (AddGoods.html & AddGoodsServlet)

**访问地址**：
- `/Administrator/AddGoods.html`

**功能**：
- 输入商品名称
- 输入所需积分
- 输入商品描述（可选）
- 点击"添加商品"
- itemID 自动按顺序生成

**参数**：
- `itemName` - 商品名称
- `needPoint` - 所需积分
- `desc` - 商品描述

## 查询交易记录

### 查看某用户的交易记录
```sql
SELECT * FROM pointop WHERE userID = '13800000001' ORDER BY `time` DESC;
```

### 查看所有交易记录
```sql
SELECT u.userName, p.pointOP, p.detail, p.`time`
FROM pointop p
JOIN user u ON p.userID = u.userphone
ORDER BY p.`time` DESC;
```

### 统计用户总交易数
```sql
SELECT userID, COUNT(*) as tradeCount FROM pointop GROUP BY userID;
```

## 常见问题

### Q：兑换后积分没有扣除？
A：
1. 检查 pointop 表是否创建成功
2. 查看Tomcat日志是否有异常
3. 检查数据库连接是否正常

### Q：页面显示"暂无商品"？
A：
1. 检查 goods 表是否创建
2. 检查是否正确插入了初始商品
3. 查看SQL是否有错误

### Q：兑换按钮一直是灰色（禁用）？
A：
1. 检查用户积分是否足够
2. 查看 points 表中用户的积分值
3. 刷新页面重新加载数据

### Q：翻页不工作？
A：
1. 检查是否有超过9个商品
2. 查看分页参数是否正确传递
3. 检查Tomcat日志
