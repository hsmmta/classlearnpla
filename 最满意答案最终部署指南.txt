### 阶段1：数据库更新

#### 问题原因
你的 MySQL 版本不支持 `IF NOT EXISTS` 语法（MySQL 5.7及以下版本）。

#### 解决方案
执行以下 SQL（**去掉 IF NOT EXISTS**）：

```sql
USE web_demo;

-- 1. 为 question 表添加最满意答案ID列
ALTER TABLE question ADD COLUMN bestAnswerID INT DEFAULT NULL COMMENT '最满意答案的评论ID';

-- 2. 为 question_comment 表添加最满意答案标记列
ALTER TABLE question_comment ADD COLUMN isBestAnswer TINYINT(1) DEFAULT 0 COMMENT '是否为最满意答案：0-否，1-是';

-- 3. 验证
DESC question;
DESC question_comment;

-- 应该看到两个新增的列
```

**执行步骤**：
1. 打开 MySQL 客户端
2. 输入密码：`123456ks`
3. 复制上面的 SQL 代码逐行执行
4. 如果看到 `DESC` 的结果中有新列，说明添加成功 ✅

**可能的错误**：
- 如果看到 `Duplicate column name` 错误，说明列已经存在了，可以忽略

### 查询已设置的最满意答案

```sql
-- 查看所有已设置最满意答案的问题
SELECT q.questionID, q.questionTitle, q.bestAnswerID,
       qc.userID as answerOwner, u.userName, qc.commentContent
FROM question q
LEFT JOIN question_comment qc ON q.bestAnswerID = qc.commentID
LEFT JOIN user u ON qc.userID = u.userphone
WHERE q.bestAnswerID IS NOT NULL;

-- 查看某用户获得的最满意答案数量
SELECT COUNT(*) as bestAnswerCount
FROM question_comment
WHERE userID = '用户的手机号' AND isBestAnswer = 1;

-- 查看某用户因最满意答案获得的积分
SELECT * FROM pointop
WHERE userID = '用户的手机号'
  AND detail LIKE '%获得最满意答案%'
ORDER BY time DESC;
```

- 代码没有重新编译部署
- 浏览器缓存

**解决**：
```bash
# 1. 检查数据库
DESC question;
DESC question_comment;

# 2. 重新编译和部署
mvn clean compile mvn package

# 3. 删除 Tomcat 的 work 目录
# 4. 重启 Tomcat
# 5. 清除浏览器缓存（Ctrl+Shift+Delete）
```

#### 2. 点击按钮后报错
**原因**：
- SetBestAnswerServlet 没有编译
- 路由配置有问题

**解决**：
```bash
# 检查 SetBestAnswerServlet 文件是否存在
ls -la src/main/java/org/example/servlet/discussion/SetBestAnswerServlet.java

# 重新编译
mvn clean compile mvn package
```

#### 3. 按钮点击后没有反应
**原因**：
- Tomcat 没有重启
- 旧代码还在运行

**解决**：
```
1. 停止 Tomcat
2. 删除 webapps/焚决 和 work/Catalina/localhost/焚决
3. 重启 Tomcat
4. 等待自动解压
5. 刷新页面（Ctrl+F5）
```
