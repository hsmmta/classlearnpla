## 🚀 编译和部署

### 方式1：Maven命令行部署（推荐）


## 🔍 常见问题排查

### 问题1：404 Not Found

**可能原因**：
- 应用未正确部署
- 访问路径错误

**排查步骤**：
```
1. 检查Tomcat webapps目录下是否有焚决文件夹或焚决.war
2. 检查访问地址：http://localhost:8080/焚决/auth/signin.html
3. 查看Tomcat logs/catalina.out是否有错误
```

### 问题2：500 Internal Server Error

**可能原因**：
- Java代码异常
- 数据库连接失败

**排查步骤**：
```
1. 查看Tomcat日志：tail -f logs/catalina.out
2. 查看错误堆栈信息
3. 如果是SQLException，检查数据库连接
4. 如果是NullPointerException，检查Session是否为空
```

### 问题3：无法连接数据库

**可能原因**：
- MySQL未启动
- DBUtil中的连接信息不正确
- 数据库或表不存在

**排查步骤**：
```
1. 检查MySQL是否运行：
   # Windows
   tasklist | findstr mysql
   # Linux
   ps aux | grep mysql

2. 检查MySQL连接：
   mysql -u root -p

3. 验证数据库存在：
   SHOW DATABASES;
   USE web_demo;
   SHOW TABLES;

4. 验证表结构：
   DESC user;
```

### 问题4：页面显示乱码

**原因**：编码问题

**解决**：
```
1. 检查JSP页面头：<%@ page contentType="text/html;charset=UTF-8" %>
2. 检查HTML meta标签：<meta charset="UTF-8">
3. 检查IDE编辑器编码设置
4. 清除浏览器缓存
```

### 问题5：表单无法提交

**可能原因**：
- form action路径错误
- Servlet路由配置错误
- JavaScript错误

**排查步骤**：
```
1. 检查form action是否使用了contextPath
2. 检查Servlet的@WebServlet路由
3. 打开浏览器开发者工具查看网络请求
4. 查看浏览器console是否有JavaScript错误
```

## 🛠️ 故障排除流程

如果部署后仍有问题，按以下流程排查：

```
1. 验证部署
   └─ 检查Tomcat是否启动
   └─ 检查应用是否正确部署
   └─ 访问简单的JSP（如登录页）

2. 检查数据库
   └─ 检查MySQL是否运行
   └─ 检查能否连接到MySQL
   └─ 检查数据库和表是否存在

3. 检查代码
   └─ 重新编译：mvn clean compile
   └─ 检查是否有编译错误
   └─ 检查修复是否应用正确

4. 查看日志
   └─ 查看Tomcat catalina.out
   └─ 找到具体错误信息
   └─ 根据错误信息进行修正

5. 清除缓存
   └─ 删除target目录
   └─ 删除.m2缓存（可选）
   └─ 重新编译部署
```
