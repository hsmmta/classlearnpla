## 核心修复点

### forgetPassword.jsp
```jsp
<%
    // 新增：检查用户是否已登录和绑定邮箱
    String userID = (String) session.getAttribute("userID");
    String userEmail = (String) session.getAttribute("userEmail");

    if (userID == null || userID.trim().isEmpty()) {
        response.sendRedirect(request.getContextPath() + "/auth/signin.html");
        return;
    }

    if (userEmail == null || userEmail.trim().isEmpty()) {
        response.sendRedirect(request.getContextPath() + "/personalInfo/changeUserInfo.jsp?msg=请先绑定邮箱");
        return;
    }
%>
```

### cancelUser.html
```javascript
// 新增：动态获取contextPath
function getContextPath() {
    var pathName = window.location.pathname;
    var index = pathName.indexOf('/personalInfo');
    if (index !== -1) {
        return pathName.substring(0, index);
    }
    return '/焚决'; // 默认应用名
}

// 修改：使用动态路径而不是硬编码
xhr.open("POST", window.location.origin + contextPath + "/deleteAccount", true);

// 修改：返回按钮使用动态路径
function goBack() {
    var contextPath = getContextPath();
    window.location.href = window.location.origin + contextPath + "/personalInfo/getUserInfo.jsp";
}
```

## 常见问题

### Q：找回密码还是显示404？
A：
1. 确保执行了 `mvn clean`
2. 确保删除了 `webapps/焚决` 整个文件夹
3. 确保已登录且绑定了邮箱
4. 强制清除浏览器缓存

### Q：注销账户点击没反应？
A：
1. 打开浏览器开发者工具（F12）
2. 查看Console中是否有JavaScript错误
3. 查看Network中POST请求是否返回200
4. 检查Tomcat日志

### Q：跳转到登录页失败？
A：
1. 检查应用是否正确部署
2. 查看contextPath是否正确（可能不是/焚决）
3. 检查Tomcat日志
