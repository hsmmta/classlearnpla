# Android App 适配差异清单

本清单用于说明当前 `Vue + Capacitor` 路线与参考设计 `其他功能参考资料/projectCode` 的映射关系，以及本次统一的移动端样式基线。

## 结构差异

- 当前方案：Capacitor Android 壳 + 远程加载 Vue SPA（共享同一套后端接口）。
- 参考方案：原生 Compose UI 原型，接口未完整接入。
- 落地策略：保留现有业务逻辑和 API，吸收参考设计的移动端视觉元素与页面布局密度。

## 样式 Token（本次统一）

- 主色：`#0088FF`
- 深色背景：`#1F2937`
- 文本弱化：`#6B7280`
- 成功色：`#4CAF50`
- 警示色：`#FF9800`
- 卡片阴影：`shadow-card`
- 移动端按钮：圆角 `rounded-lg`，默认 `py-2.5`

## 页面映射

- 学生首页：保留功能入口数量，采用更紧凑的移动网格和大按钮视觉。
- 资料区 / 讨论区 / 积分商城 / 个人中心：沿用现有路由与接口，强化移动端卡片和按钮触达区。
- 管理端：保留全部管理能力，重点优化小屏导航与操作按钮可点区域。

## 非功能约束

- 不改变现有后端业务规则（积分、审核、封禁、楼中楼等）。
- 不改动 API 路径和会话模型（仍基于 `/api/*` + cookie session）。
- 真机联调仍采用局域网地址配置 `APP_SERVER_URL`。
