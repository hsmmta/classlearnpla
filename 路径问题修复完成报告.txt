焚决项目 - 个人信息路径问题修复完成
===================================

## 问题诊断

### 错误信息
```
The requested resource is not available.
/Prize/changeUserInfo.jsp
```

### 根本原因
`getUserInfo.jsp` 中的"修改信息"按钮使用了相对路径 `changeUserInfo.jsp`，在某些Tomcat配置下会被错误地解析为 `/Prize/changeUserInfo.jsp`。

---

## 修复完成 ✅

### 修改的文件

#### 1. **getUserInfo.jsp** ✅ 已修复
修复内容：
- 导航栏所有链接改为使用 `${pageContext.request.contextPath}`
- "修改信息"按钮路径：`changeUserInfo.jsp` → `${pageContext.request.contextPath}/personalInfo/changeUserInfo.jsp`
- "修改密码"按钮路径：`changePassword.html` → `${pageContext.request.contextPath}/personalInfo/changePassword.jsp`
- "找回密码"按钮路径：`forgetPassword.jsp` → `${pageContext.request.contextPath}/personalInfo/forgetPassword.jsp`
- "注销账号"函数：`/personalInfo/cancelUser.html` → `${pageContext.request.contextPath}/personalInfo/cancelUser.html`

#### 2. **changePassword.html** ✅ 已修复
修改内容：
- AJAX请求路径：`/changePassword` → `window.location.origin + "/焚决/changePassword"`
- 登录页跳转：`/auth/signin.html` → `window.location.origin + "/焚决/auth/signin.html"`

#### 3. **forgetPassword.jsp** ✅ 已验证
状态：无需修改，已正确使用 `${pageContext.request.contextPath}`

   查看是否有404或其他错误

2. **检查文件位置**
   ```bash
   ls -la src/main/webapp/personalInfo/
   # 应该看到 changeUserInfo.jsp、changePassword.html 等文件
   ```

3. **检查部署**
   ```bash
   ls -la $TOMCAT_HOME/webapps/焚决/personalInfo/
   # 应该看到已部署的文件
   ```

4. **强制重新部署**
   - 删除 `$TOMCAT_HOME/webapps/焚决` 整个目录
   - 删除 `$TOMCAT_HOME/work/Catalina/localhost/焚决` 目录
   - 重新启动Tomcat，让它自动重新解压WAR包
