积分商城 JSP 编译错误 - 已修复
=============================

## 错误原因

JSP 使用了 Java 7+ 的特性，但 Tomcat 配置的是 Java 6：

1. **菱形运算符 `<>`**：Java 7 引入的特性，Java 6 不支持
2. **类型转换错误**：`(int)item.get("needPoint")` 无法直接从 Object 转换为 int

---

## 已完成的修复 ✅

### 修复1：ArrayList 初始化
```java
// 修改前（Java 7+）
List<Map<String, Object>> goods = new ArrayList<>();

// 修改后（Java 6兼容）
List<Map<String, Object>> goods = new ArrayList<Map<String, Object>>();
```

### 修复2：HashMap 初始化
```java
// 修改前（Java 7+）
Map<String, Object> item = new HashMap<>();

// 修改后（Java 6兼容）
Map<String, Object> item = new HashMap<String, Object>();
```

### 修复3：类型转换
```java
// 修改前（错误）
<% if (userPoints < (int)item.get("needPoint")) { %>

// 修改后（正确）
<% if (userPoints < ((Integer)item.get("needPoint")).intValue()) { %>
```
