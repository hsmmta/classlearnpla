## SQL 查询示例

### 查看所有待审核资料
```sql
SELECT materialID, materialTitle, uploaderName, uploadTime, materialState
FROM material
WHERE materialState = '待审核'
ORDER BY uploadTime DESC;
```

### 查看所有待审核问题
```sql
SELECT questionID, questionTitle, u.userName, q.creationTime, questionState
FROM question q
JOIN user u ON q.userID = u.userphone
WHERE questionState = '待审核'
ORDER BY creationTime DESC;
```

### 手动更新审核状态（测试用）
```sql
-- 通过资料
UPDATE material SET materialState = '审核通过' WHERE materialID = 'xxx';

-- 拒绝资料
UPDATE material SET materialState = '审核不通过' WHERE materialID = 'xxx';

-- 通过问题
UPDATE question SET questionState = '审核通过' WHERE questionID = 'xxx';

-- 拒绝问题
UPDATE question SET questionState = '审核不通过' WHERE questionID = 'xxx';
```

## 常见问题

### Q：用户上传的资料没有设置为"待审核"状态？
**A**：检查 UploadMaterialServlet.java 第57行，应该是：
```java
pstmt.setString(7, "待审核");
```

### Q：资料审核通过后用户端还是看不到？
**A**：检查 SearchMaterialServlet.java，SQL 查询应该有：
```sql
WHERE materialState = '审核通过'
```

### Q：管理员审核页面显示"无权限"？
**A**：确认管理员登录后 session 中有：
```java
session.getAttribute("userType") == "admin"
```

### Q：审核后状态没有更新？
**A**：
1. 检查 UpdateMaterialStateServlet 或 UpdateQuestionStateServlet
2. 查看 Tomcat 日志是否有 SQL 错误
3. 确认数据库连接正常
