管理员登录问题修复完成
====================

## 问题诊断

### 问题现象
管理员输入账号和密码后，提示"请输入正确的11位手机号"，无法登录。

### 根本原因
登录页面（signin.html）的前端验证强制要求输入11位手机号格式，导致管理员账号（不是手机号格式）被拦截，无法提交到后端验证。

---

## 已完成的修复 ✅

### 修改的文件
`src/main/webapp/auth/signin.html`

### 修复内容

#### 1. 修改前端验证逻辑 ✅
**修改前**：
```javascript
// 强制要求手机号格式
if (!/^1[3-9]\d{9}$/.test(phone)) {
    alert("请输入正确的11位手机号！");
    return false;
}
```

**修改后**：
```javascript
// 允许管理员账号或手机号
let userID = document.getElementById("userID").value.trim();

if (!userID) {
    alert("请输入手机号或管理员账号！");
    return false;
}

// 只有验证码登录时才强制要求手机号格式
let loginType = document.querySelector('input[name="loginType"]:checked').value;
if (loginType === "code" && !/^1[3-9]\d{9}$/.test(userID)) {
    alert("验证码登录需要输入正确的11位手机号！");
    return false;
}
```

#### 2. 修改输入框提示 ✅
**修改前**：
```html
手机号：<input ... placeholder="请输入11位手机号" maxlength="11">
```

**修改后**：
```html
账号：<input ... placeholder="请输入手机号或管理员账号">
```
（移除了 maxlength="11" 限制）

#### 3. 修改验证码发送函数 ✅
更新变量名，确保验证码登录仍然需要手机号格式。

## 登录逻辑说明

### 后端登录流程（LoginServlet）

1. **接收登录请求**
   - userID（可以是手机号或管理员账号）
   - userPassword
   - loginType（password 或 code）

2. **密码登录流程**：
   ```
   ① 先在 user 表中查找（普通用户）
      - 如果找到 → 验证密码 → 跳转到 /home/index.jsp
      - 如果没找到 → 继续第②步

   ② 在 admin 表中查找（管理员）
      - 如果找到且密码正确 → 跳转到 /Administrator/index.jsp
      - 如果没找到或密码错误 → 登录失败
   ```

3. **验证码登录流程**：
   - 只支持普通用户（user 表）
   - 管理员不能使用验证码登录

## 常见问题

### Q：管理员登录后提示"手机号或密码错误"？
A：
1. 检查 admin 表是否存在
2. 检查管理员账号和密码是否正确
3. 查看 Tomcat 日志是否有 SQL 错误

### Q：管理员登录后跳转到普通用户首页？
A：
1. 检查 LoginServlet 中的 verifyAdmin 方法
2. 确保 redirectUrl 设置为 `/Administrator/index.jsp`

### Q：普通用户也无法登录了？
A：
1. 确保修改后没有破坏普通用户登录逻辑
2. 测试手机号格式的账号登录
3. 查看 Tomcat 日志
