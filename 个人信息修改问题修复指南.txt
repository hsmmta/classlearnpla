## 问题2修复：修改个人信息

### 可能的原因

user表中可能缺少以下列：
- `gender` (性别)
- `studentID` (学号)

### 修复步骤

#### 步骤1：检查user表结构

```bash
# 连接到MySQL
mysql -u root -p

# 进入数据库
USE web_demo;

# 查看user表结构
DESC user;
```

你应该看到类似的输出：
```
+------------------+--------------+------+-----+---------+-------+
| Field            | Type         | Null | Key | Default | Extra |
+------------------+--------------+------+-----+---------+-------+
| userphone        | varchar(20)  | NO   | PRI | NULL    |       |
| userPassword     | varchar(50)  | YES  |     | NULL    |       |
| userName         | varchar(20)  | YES  |     | NULL    |       |
| classID          | varchar(15)  | YES  |     | NULL    |       |
| studentID        | varchar(15)  | YES  |     | NULL    |       | <- 需要这列
| gender           | varchar(10)  | YES  |     | NULL    |       | <- 需要这列
| userEmail        | varchar(50)  | YES  |     | NULL    |       |
| userStatus       | int(11)      | YES  |     | NULL    |       |
+------------------+--------------+------+-----+---------+-------+
```

#### 步骤2：如果缺少列，执行以下SQL

在MySQL中执行这些命令：

```sql
-- 如果缺少studentID列，执行：
ALTER TABLE user ADD COLUMN studentID VARCHAR(15) AFTER classID;

-- 如果缺少gender列，执行：
ALTER TABLE user ADD COLUMN gender VARCHAR(10) AFTER userEmail;

-- 验证结果
DESC user;
```

#### 步骤3：如果user表完全不存在或结构错误

创建完整的user表：

```sql
-- 如果表不存在，先删除（如果存在的话）
-- DROP TABLE IF EXISTS user;

-- 创建新的user表
CREATE TABLE user (
    userphone VARCHAR(20) PRIMARY KEY,
    userPassword VARCHAR(50),
    userName VARCHAR(20),
    classID VARCHAR(15),
    studentID VARCHAR(15),
    gender VARCHAR(10),
    userEmail VARCHAR(50),
    userStatus INT DEFAULT 1
);

-- 如果有原来的数据，需要重新导入或手动插入
-- 插入测试账号示例：
INSERT INTO user (userphone, userPassword, userName, classID, studentID, gender, userEmail, userStatus)
VALUES ('13800000001', 'password123', '张三', '班级1', 'S001', 'male', 'test@example.com', 1);
```

## 常见问题

### Q：数据库修复脚本在哪里？
A：文件名是 `数据库修复脚本.sql`，在项目根目录

### Q：怎么执行SQL脚本？
A：
```bash
# 方式1：在MySQL命令行中复制粘贴SQL语句执行
mysql> USE web_demo;
mysql> ALTER TABLE user ADD COLUMN studentID VARCHAR(15) AFTER classID;

# 方式2：使用MySQL客户端工具（如Navicat、DBeaver）
# 方式3：在命令行中执行
mysql -u root -p web_demo < 数据库修复脚本.sql
```

### Q：我的数据会丢失吗？
A：不会。`ALTER TABLE ADD COLUMN` 只是添加新列，不会删除现有数据。

### Q：如果我不想手动执行SQL怎么办？
A：可以使用MySQL图形工具：
- Navicat
- DBeaver
- MySQL Workbench
- PhpMyAdmin
