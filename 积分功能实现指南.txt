焚决项目 - 积分功能实现指南
============================

## 功能概述

添加了一个新的积分系统，用户可以在个人中心查看自己的积分。

---

## 实现内容

### 1️⃣ 数据库表创建

#### 创建 points 表
```sql
CREATE TABLE IF NOT EXISTS points (
    userID VARCHAR(20) PRIMARY KEY,
    userName VARCHAR(20),
    points INT DEFAULT 0,
    FOREIGN KEY (userID) REFERENCES user(userphone),
    FOREIGN KEY (userName) REFERENCES user(userName)
);
```

**表结构说明**：
- `userID` (VARCHAR(20), PRIMARY KEY)：用户ID，与user表的userphone关联
- `userName` (VARCHAR(20))：用户名，与user表的userName关联
- `points` (INT, DEFAULT 0)：用户积分，默认为0

### 2️⃣ 修改个人信息页面

#### 修改的文件：`getUserInfo.jsp`

**添加的内容**：
1. 页面开头添加了Java代码块，用于查询用户积分
2. 在邮箱项后添加了积分显示项
3. 积分显示为橙色加粗，便于用户识别

```html
<!-- 个人积分 -->
<div class="info-item">
    <span class="info-label">个人积分</span>
    <span class="info-value" id="points" style="color: #ff9800; font-weight: bold;">
        <%= userPoints %>
    </span>
</div>
```

### 3️⃣ 创建积分更新 Servlet

#### 新建文件：`UpdatePointsServlet.java`

**功能**：
- 提供 POST 接口 `/updatePoints` 用于更新用户积分
- 接受参数：`userID`（用户ID）和 `points`（新的积分值）
- 返回 JSON 格式的响应

**使用示例**：
```javascript
// 在需要更新积分的地方调用
let xhr = new XMLHttpRequest();
xhr.open("POST", "/updatePoints", true);
xhr.setRequestHeader("Content-Type", "application/x-www-form-urlencoded");
xhr.send("userID=13800000001&points=100");
```

## 查询和更新积分

### 查询用户积分

在个人中心页面，积分会自动从 points 表中查询并显示。

### 更新用户积分

在任何需要更新积分的地方，可以调用 UpdatePointsServlet：

```javascript
// JavaScript 示例
function updateUserPoints(userID, newPoints) {
    let xhr = new XMLHttpRequest();
    xhr.open("POST", "/updatePoints", true);
    xhr.setRequestHeader("Content-Type", "application/x-www-form-urlencoded");

    xhr.onreadystatechange = function() {
        if (xhr.readyState === 4 && xhr.status === 200) {
            let result = JSON.parse(xhr.responseText);
            if (result.success) {
                console.log("积分更新成功");
                // 重新加载页面以显示新的积分
                location.reload();
            } else {
                alert("积分更新失败：" + result.msg);
            }
        }
    };

    xhr.send("userID=" + userID + "&points=" + newPoints);
}
```

### Java 中更新积分

```java
// 在任何 Servlet 中都可以调用
UpdatePointsServlet servlet = new UpdatePointsServlet();
// 需要自己实现逻辑来调用更新方法
```

## 注意事项

1. **确保 user 表中的所有用户都有对应的 points 记录**
   - 脚本中的 `INSERT IGNORE INTO` 可以为现有用户初始化积分

2. **新注册用户需要在 points 表中创建记录**
   - 可以在 RegisterServlet 中添加代码

3. **确保 userphone 列存在于 user 表中**
   - points 表依赖 user 表的 userphone 列作为外键

4. **数据库连接信息**
   - UpdatePointsServlet 使用的是 DBUtil 中配置的数据库连接
   - 确保数据库地址、用户名、密码正确
