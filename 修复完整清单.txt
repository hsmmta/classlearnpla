资料区和讨论区功能修复完整清单
====================================

问题根本原因：
1. Session属性名不一致 - 多个Servlet使用了错误的session属性名"phone"而不是"userID"
2. JSP路径问题 - 使用了硬编码的绝对路径而不是相对于contextPath的路径
3. 缺少会话检查 - 某些Servlet没有验证用户是否已登录
4. 错误处理不足 - 数据库连接失败没有得到正确处理

关键信息：
==========

1. LoginServlet设置的session属性：
   session.setAttribute("userID", userID);      // 用户手机号
   session.setAttribute("userName", userName);
   session.setAttribute("classID", classID);
   session.setAttribute("gender", gender);
   session.setAttribute("studentID", studentID);
   session.setAttribute("userEmail", userEmail);

2. 所有其他Servlet应该使用getAttribute("userID")来获取用户ID

3. 会话检查标准模式：
   HttpSession session = request.getSession();
   String userID = (String) session.getAttribute("userID");
   if (userID == null) {
       response.sendRedirect(request.getContextPath() + "/auth/signin.html");
       return;
   }

4. 数据库连接检查标准模式：
   conn = DBUtil.getConnection();
   if (conn == null) {
       throw new SQLException("无法获取数据库连接");
   }
